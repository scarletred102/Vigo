# Security Policy

Vigo is pre-release browser software. Security reports are especially valuable, including issues in navigation, content isolation, storage, networking, extensions, media, and the Rust/Zig FFI boundary.

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability. Use a private GitHub security advisory for this repository when it is available, and include:

- a clear description and impact assessment;
- minimal reproduction steps or a proof of concept;
- the affected revision or release; and
- any suggested mitigation, if known.

Please avoid accessing other users' data, disrupting services, or publicly disclosing the issue before maintainers have had a chance to investigate and coordinate a fix.

## Supported versions

There are no supported stable releases yet. Security fixes land on the active development branch and will be included in the next public release once the project has a release process.
