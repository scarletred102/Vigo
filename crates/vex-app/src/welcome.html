Welcome to Vigo

A privacy-first browser built from scratch with Rust and Zig.

Custom engine. No Chromium. No compromises.

Engine Features

Full HTML parser with DOM tree construction

CSS cascade and style computation

Block and flex layout engine

GPU-accelerated rendering via wgpu

Text rasterization with glyph atlas

Privacy by Default

Tracking parameter stripping, HTTPS-only mode, and cross-origin referrer reduction are built into the core engine.
