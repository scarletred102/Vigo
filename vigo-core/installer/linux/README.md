# Vigo Installer — Linux

Output formats: .deb, .rpm, AppImage

## Features
- Desktop entry (.desktop file)
- MIME type registration
- Default browser registration
- Automatic updates via APT/YUM repos

- `vigo.desktop` — FreeDesktop entry
- `debian/` — Debian packaging files

- `appimage/` — AppImage build scripts
