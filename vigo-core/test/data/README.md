# Vigo Test Data

This directory contains test fixtures, filter lists, and media samples
for Vigo's automated test suites.

## Subdirectories (to be created as tests are written)

- `adblock/` — Sample EasyList filter files
- `crypto/` — NIST/RFC test vectors for crypto operations
- `media/` — Short media clips in various formats for codec tests
- `sync/` — Encrypted blob fixtures for sync roundtrip tests
